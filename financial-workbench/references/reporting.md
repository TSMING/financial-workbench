# 从资料到财报

## 输入与口径

优先使用已有资料确认报告主体、期间/比较期间、合并或单体、适用 IFRS/AASB、主体类型及 Tier、功能/列报币种和金额单位。只追问会改变结果的缺口，同时先做独立可完成的分析。

完整编制通常需要 TB/GL、期初/比较余额、COA 映射、会计政策，以及现金、债务、权益、税务、固定资产、租赁和集团内部往来等相关明细。材料不齐时产出已知项目和缺数清单；不能从一段并购摘要制造全套财务数据。

## 编制链

保留不可修改的输入快照；记录每项重分类/调整及其证据，逐笔校验借贷；生成 adjusted TB 后映射报表科目。调整分录、抵销分录和汇率变动分别保存。

| 交付 | 关键勾稽 |
| --- | --- |
| Statement of financial position | Assets = liabilities + equity；对应 adjusted TB |
| Profit or loss and OCI | 当期损益、OCI 与权益变动衔接；比较数和分类口径一致 |
| Changes in equity | 各权益类别期初 + 期间变动 = 期末；NCI 单独衔接 |
| Cash flows | 现金期初 + 现金流净额 + 汇率影响 = 期末；非现金交易单独披露 |
| Notes | 会计政策、重大判断/估计、并购、商誉、债务/金融工具等与主表金额对应 |

现金流分类不能只靠科目名称或借贷方向猜测；根据实际现金记录和非现金明细分离收购、再融资、费用与其他变动。合并时核实收购日、收购后损益、NCI、内部交易和余额抵销。

按报告期及提前采用事实确认 IAS 1/IFRS 18、AASB 101/AASB 18 的适用版本。不能仅因当前年份改变历史期间的列报准则；也不能把 IFRS 生效安排直接套到所有澳大利亚主体。

## 输出状态

用“草稿/缺数/已勾稽”等实际状态描述，不把算术平衡称为准则合规或审计完成。电子表格保留输入、映射、调整、输出及校验之间的公式关系；环境有相应文件技能时按其流程导出并检查。否则交付可复核表格/CSV 或结构化结果，不声称已经生成工作簿。
