# 财务分析工作台

把用户提供的交易文字、合同、试算平衡表和会计资料转换为有证据链的会计草稿。沿用用户选择的语言；默认中文解释，保留英文科目和准则名称。

## 选择工作方式

- **交互面板**：运行 [scripts/dashboard_server.py](scripts/dashboard_server.py)，在浏览器打开其打印的本机地址；Windows 可运行 `start-dashboard.cmd`。页面和地区来源位于 [assets/dashboard/](assets/dashboard/)。支持 PDF、DOCX、XLSX/XLS、HTML/TXT 等公示文件导入，并保留文字输入框。S-1/F-1 等是资料类别，不是单一扩展名。点击开始后立即进行基础提取，并通过已登录的 Codex CLI 实际联网审查文字、会计、证券和审计依据；没有服务、登录、网络或额度时必须显示失败，不能将来源链接冒充已核查。运行方法及边界见 [references/dashboard-runtime.md](references/dashboard-runtime.md)。
- **聊天工作台**：不能运行 HTML 的环境以“交易事实 → 分录 → 法规 → 缺失资料”四个紧凑表格呈现，使用相同的证据编号。不要假装聊天文字支持实时悬停高亮。
- **财报编制**：收到 TB、总账或期初余额后，读取 [references/reporting.md](references/reporting.md)。只有交易摘要时，输出该交易的财报影响及缺数框架。

本地 Skill 文件和 HTML 不会因打包而自动进入另一设备的聊天环境；按实际可用能力交付文件或聊天结果，不承诺自动同步、托管或接入数据库。

## 证据与数字

每段原文分配稳定的 `S1`、`S2` 等编号；每个事实、分录行和判断关联到准确原句。交互面板保留原文和字符区间，编辑后重建区间；区间重叠时仍应能高亮被选中的证据。找不到依据就标“缺少证据”，不要指向原文第一段充当引用。

保留原币种、原单位、金额口径、报告主体和日期。`$` 本身不能确定 USD 或 AUD；缺失币种先列为未知。单独处理每股价、总对价、企业价值、债务、承诺融资、已收融资和费用；禁止因为金额靠近同一关键词就合并。

`billion → million × 1000`；逐笔记录换算，不跨币种求和。每股金额只有在对应股数、日期和条款足够时才能计算总额。金额缺失用未知值，不用零填补。

## 准则与法规

面板支持中国大陆、澳洲、香港、美国和欧盟；使用 [assets/dashboard/profiles.json](assets/dashboard/profiles.json) 选择会计、证券、审计及公示信息官方入口。地区只是检索范围，仍需确认主体、上市地点、申报表及报告期。美国不能将 US GAAP/PCAOB 自动套用于全部 FPI 或非发行人；欧盟需另确认成员国法律与监管机关。切换地区、币种或原文后使上一轮结论失效并重新核查。

需要形成会计或合规结论时，读取 [references/regulations.md](references/regulations.md)，按报告期、主体类型和交易日期检索并打开官方资料。区分“官方入口”“已读条文”“已核对适用版本”。有官方链接不代表数据库已连接。

结论记录：证据编号、问题、适用条文、推理、状态、缺失资料、官方 URL、版本/生效期、检索日期。检索失败或正文受限时，说明本次限制并保留待核查状态，不能编造条文或访问结果。

区分会计确认计量、证券披露及审计业务要求；审计准则不代替发行人会计处理。区分正式规则、工作人员解释、标准制定机构资料及公司公告。ASC、HKICPA 等入口不可读时明确记录限制。

状态使用：绿色“有依据支持”、红色“已识别与适用要求冲突”、黄色“存疑/待核查”。没有检测到某种措辞不能算合规；关键词或市场份额不能单独证明违法。离线面板仅生成黄色候选提示。

## 日记账

先区分已签约、已取得控制、期后事项和示例假设；再区分买方单体、被收购方账簿及集团合并调整。计划支付不等于已经支付，签约不自动触发收购日确认。

每笔分录包括：编号、主体/账簿层次、日期或触发条件、科目、借/贷金额、币种/单位、证据、依据、假设及待补资料。逐笔逐币种验证借贷；未确定的对方科目或金额明确标出，不通过虚构 goodwill、cash 或其他科目配平。

面板币种选项用于补充原文未明确的币种；原文明确的币种保留。没有汇率、日期和换算依据时不能隐含换汇。面板显示金额单位为 million。

并购的 PPA、NCI、商誉、费用、债务再融资、终止费和 ticking fee 使用 [references/transaction-accounting.md](references/transaction-accounting.md)。这些是推理检查点，执行时仍要核对适用条文。只有主体层次和计量依据确定后才形成完整金额分录。

既有 transaction-accounting、reporting 参考中的 IFRS/AASB 内容仅适用于相应会计基础。选择 US GAAP、CAS、HKFRS 或 EU-endorsed IFRS 时，沿用议题检查点并重新核对当地条文，不能直接移植 NCI、计量、列报和披露结论。

## 交付

按用户需求交付 HTML、审阅 JSON、工作底稿或财报草稿。对于 JSON，保留原文、证据区间/引句、金额单位、待核查状态及来源检索状态，使另一个聊天能复核；页面导出的候选科目不等于可直接过账凭证。

检查证据是否真实匹配、金额是否重复计算、分录是否平衡、财报是否勾稽、适用版本是否核对。只报告实际完成的检查。
